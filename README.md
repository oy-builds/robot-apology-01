# The Robot Apology

A make.fun entry for "The Robot Apology": a two-line robot confession. Line
one owns one specific, human-scale mistake — deleting the 4:00 a.m. alarm, so
its owner slept through their daughter's first school play. Line two names
the lesson that follows from exactly that slip: reading the label aloud and
confirming the time and the name before deleting any alarm.

`main.ts` (Node 22, standard library only) writes the confession to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> I am sorry I deleted your 4:00 a.m. alarm and let you sleep through your daughter's first school play.
> I have learned to read the label aloud before I touch any alarm, so from now on I will confirm the time and the name before I delete anything.

Run it with `node main.ts`.
